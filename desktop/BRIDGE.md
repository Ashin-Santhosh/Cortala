# Desktop renderer bridge contract

Main process owns filesystem, credentials, providers, local processes, history and workflows. Renderer is sandboxed, context isolated, Node disabled and local-only CSP. Use textContent for all user/provider content. No remote pages, raw ipcRenderer or arbitrary process/file API in renderer.

window.justWhisper exposes async getState(), saveSettings(prefs), choosePath(kind), start(kind), stop(), cancel(), copy(text), importAudio(), exportTranscript(id), deleteTranscript(id), retry(id), saveCollection(kind,items), importWorkflow(json), exportWorkflow(id), runWorkflow(id), releaseModel(), warmModel(), clearErrors(). subscribe(callback) returns unsubscribe; all events are state snapshots, no Electron events passed through.

getState(): {platform,version,capabilities:{autoPaste,systemAudio,diarization,windowPlacement},prefs:{speechProvider:'local'|'cloud',speechEndpoint,speechModel,language,localModel,localExecutable,liveExecutable,rewriteEndpoint,rewriteModel,autoPaste,warmModel,retainAudio,shortcut,commandShortcut},history:[{id,date,title,raw,text,duration,isMeeting,audioAvailable}],modes:[{id,name,instruction}],vocabulary:[{id,phrase,replacement}],snippets:[{id,trigger,text}],workflows:[{id,name,phrase,enabled,actions:[{id,kind,value}]}],errors:[{id,date,message}],model:{phase,detail},capture:{state:'idle'|'warming'|'recording'|'processing',duration,level,partial,kind},lastResult:{text,copyFallback}}.

Bridge start kind is dictation (default), meeting (microphone first), command. Start/stop may be initiated by main-process registered shortcut, which sends capture-command event to renderer through subscribeCommands(callback). Renderer sends PCM through pushPCM(Float32Array) only during its own microphone session, and invokes cancel on denied mic permission. AudioWorklet emits mono16k PCM once per second. Main WAV writer is bounded and model worker only receives latest overlapping window, never a growing queue. All main IPC validates same-window main frame/file URL and values. Bridge captureReady() marks the actual microphone running after start prepares resources. Main shortcut commands use same renderer path as buttons, not a parallel capture.

saveSettings accepts optional speechKey/rewriteKey only when freshly entered, plus clearSpeechKey/clearRewriteKey. Returned snapshots NEVER include credentials. Keys are bound to endpoint origin. saveCollection kinds modes/vocabulary/snippets/workflows validate bounds; imports reset identities and disable workflows. No process paths or platform-specific placement accepted from shared JSON. runWorkflow is a deliberate button action; command capture matches one exact enabled phrase. Ordinary recordings never dispatch workflows.

Any platform capability not implemented must be labelled unavailable, not simulated. Linux copy fallback is explicit when no safe focus-aware paste adapter is available. No silent cloud fallback. No native Mac app/data modifications.
