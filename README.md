A native macOS dictation and meeting-transcription app under active development. This personal development build uses local whisper.cpp or a cloud transcription endpoint, with an independently configured language model for cleanup, translation and meeting notes. English and multilingual recognition are supported through the selected speech model. Exact Superwhisper parity is not established. Current accuracy evaluation assesses JustWhisper independently; user-voice accuracy remains unmeasured.

Windows and Linux development lives in [desktop/README.md](desktop/README.md). It has a separate sandboxed desktop interface and platform build jobs; target-device acceptance and full macOS feature parity are not yet established. Mobile development is on hold.

## Build and run

Requires macOS 14 or later, Apple's Command Line Tools with Swift 6, and Python 3 for the project-local toolchain workaround. The current build is for this Mac's architecture.

```sh
./scripts/test.sh
./scripts/build.sh
open dist/JustWhisper.app
```

The scripts use project-local caches and work around conflicting SwiftBridging module maps and stale SwiftPM interfaces found in the installed Command Line Tools. They do not edit the installed compiler. The app is ad-hoc signed for personal development; it is not a notarized public release.

For local speech recognition install whisper.cpp (`brew install whisper-cpp`) and obtain a compatible GGML model. On this development Mac, `/opt/homebrew/bin/whisper-cli` and the verified multilingual `Models/ggml-medium.bin` are available. The app detects this executable and the project model when its configured paths are empty. Check **Models library** after launch; existing configured paths take precedence. The model is about 1.53 GB and is not bundled in the app or committed with source. A copied app on another machine needs its own runtime and model paths.

The approved model's SHA-256 is `6c14d5adee5f86394037b4e4e8b59f1673b6cee10e3cf0b11bbdbee79c156208` (1,533,763,059 bytes). Model source and runtime: [whisper.cpp](https://github.com/ggml-org/whisper.cpp), [Whisper medium GGML model](https://huggingface.co/ggerganov/whisper.cpp/blob/main/ggml-medium.bin). Refer to those projects for licensing and supported models.

## First use

1. Open **Models library**, confirm the local paths or enter your cloud transcription endpoint, model ID and API key, then save providers.
2. Select **Dictation** for plain speech-to-text. Optionally set a language endpoint and model (OpenAI-compatible, native Claude/Gemini or a local server) for the Clean, Message, Email, Notes and Translate modes. A running local Ollama or LM Studio server can provide that endpoint; a cloud text endpoint sends recognized text off the Mac even when speech recognition is local. Leaving the language model empty produces raw transcription.
3. Set the default language in **Configuration**: `en` for English, `auto` for language detection, or a Whisper language code such as `de`, `fr` or `ml`. A mode's explicit language overrides the default; a mode set to `auto` inherits it. Translate mode uses the configured language model to translate recognized text to English.
4. Start recording in the app to review/copy the result. macOS requests microphone access. To insert dictation into another app, grant Accessibility access, focus an editable text field, then use **Control–Option–Space** to toggle recording or hold **Control–Option–Shift–Space** to talk. Escape cancels. Edit toggle and hold shortcuts in Configuration and assign mode shortcuts in Modes. Save to register them; duplicate assignments and OS registration errors are shown.
5. Import audio/video from the Home button, File menu or Finder Open With. Imported files produce reviewable text and are never automatically pasted. History supports search, copy/export, retained-audio playback, retry and deletion. Audio/video formats must be readable by macOS; files without a usable audio track fail with an error.

Meetings offer microphone, system audio, or both. System capture requests Screen & System Audio Recording permission. Use headphones for mixed recording to reduce feedback. Full transcription runs after recording stops; optional provisional captions preview a rolling audio window during capture. Meeting notes and transcript questions use the selected mode's language connection, or the default in Models library. Choose summary, standup, interview or decision-log templates. Long files are chunked; available provider timestamps are shown in expanded History. For anonymous offline speaker labels, enable speaker separation and download the verified 22 MB FluidAudio CoreML model set in Models library (macOS 15+). This performs real segmentation, embedding and speaker clustering on this Mac, then aligns labels to available speech-recognition timestamps; it does not identify people's names. Labels need review, especially short or overlapping turns. Missing models/timestamps or a speaker-processing failure leave the recognized transcript and captured audio available for retry. Calendar connection is an explicit action. Opt-in meeting-app suggestions distinguish real CoreAudio microphone activity on macOS 14.2+ from merely running apps; microphone use does not establish a confirmed call. A real-call recording matrix remains to be verified.

Meetings also offers **Import meeting recording…** to apply meeting templates, questions and optional offline speaker separation to an existing recording without starting live capture.

URL commands: `justwisper://mode?id=UUID` or `justwisper://mode?name=Email` selects a saved mode (names must match exactly ignoring case and be unambiguous). Start/toggle may include `?mode=Email`; unknown IDs, partial names and conflicting/unknown parameters are rejected. `justwisper://start`, `justwisper://stop`, `justwisper://toggle` (`record` is an alias), `justwisper://cancel`, and `justwisper://settings`.

## Daily workflows

- **Vocabulary** supports editing and quoted CSV import/export, including multiline replacement text. CSV imports merge phrases ignoring case and update a matching phrase's replacement. Recognition hints and deterministic word replacements are separate.
- **Snippets** expand distinctive spoken triggers into saved text before optional formatting. History's action menu can apply the selected mode to saved raw text without retaining audio. Home shows activity counts for completed jobs.
- **Tone** is adjustable per mode with a Casual–Formal slider, enabled by default for new Message/Email modes. It adds a separate user-selected style instruction while preserving facts, names, language and intent; raw modes remain raw.
- **Modes** select independent speech/language provider connections, each with its own UUID, purpose, endpoint, model and Keychain credential, plus optional model overrides. Connection credentials are tied to ID and normalized endpoint origin (scheme, host, effective port). Changing origins requires its own key, and an empty connection key never falls back to a default key. Deleting a selected connection leaves an explicit missing-connection error until you select a replacement or deliberately choose the default provider.
- **Transcript correction** is explicit: History → Edit transcript preserves the original recognition. Optional learning compares your actual saved edit, presents bounded word replacements that occurred in the recognized text, and adds only corrections you select and confirm. Other applications are not monitored for corrections.
- **Desktop controls** include an optional extra mouse-button toggle/hold binding, a dedicated mode switcher with separate Choose and Record actions, and Classic/Mini/None recording indicators. Keyboard and mouse gestures own only the recording they start. Existing libraries keep the mode-switcher shortcut disabled until you enable it; new configurations offer Control–Option–K.
- **Context** is off by default. Recent-clipboard context is a separate opt-in limited to text copied within three seconds, excluding concealed pasteboard types. Configuration offers nearby-text and selected-text context, bounded to two minutes in memory, with secure/sensitive field exclusions. A mode shortcut transforms selected text when selected-text context is enabled; otherwise it starts dictation in that mode. An explicit selection transformation is saved in History and validates the original field and selection before insertion.
- **Captions and devices** are configurable. Choose **Apple Speech · on-device streaming** for true incremental hypotheses from capture buffers, or **Selected speech provider · rolling previews** for recognition of a recent 24-second window about every six seconds. Apple captions require explicit Speech Recognition permission at recording start and supported on-device recognition for the selected language; they never fall back to remote recognition. Automatic caption language uses this Mac's language. Mixed meetings label the separate live inputs Microphone/System audio; these are input names, not speaker identities. Rolling cloud previews create extra provider requests. Both caption engines remain provisional: after Stop, your selected final speech model transcribes the full recording, and partial text is never pasted. Choose a microphone without changing the Mac's system default.
- **Model downloads** offer official multilingual tiny/base/small/medium models with progress, cancellation, disk-space checks and SHA256 verification. Canceled downloads restart cleanly. Choose an existing model path to use the already downloaded development model. Ollama's installed `qwen3:8b` is available as an optional local formatting preset on this Mac.
- **Sound** offers optional recording cues and speaker ducking, off by default. Speaker volume is restored only when it still matches the app's reduced value; unsupported devices show a warning. Configuration offers system, light and dark appearance.
- **Launch at login** uses macOS Login Items and only registers after you change that setting. A packaged app is required.

## Storage and recovery

Settings and transcript history are saved at `~/Library/Application Support/JustWisper/library.json`. The library directory is private (0700), and its library/backup files use 0600 permissions. API keys are stored separately in macOS Keychain. Default provider credentials are also scoped to normalized endpoint origins; legacy unscoped keys are preserved but require re-entry once, so an imported endpoint cannot inherit another host's key. Configuration export includes modes, vocabulary, snippets, provider connections and settings, excluding key material and history. Provider endpoint URLs should not contain credentials.

Successful audio is deleted by default. Enable retention to replay and transcribe it again; the retention-days setting expires saved audio while keeping transcript text, or choose indefinite retention to keep successful audio until you explicitly delete it. Untranscribed recovery recordings remain until explicitly deleted. Deleting a history entry removes its managed recording; imported original files are kept. Configuration offers confirmed deletion of all history and recordings. An unreadable library is preserved in a separate file before a fresh library is created; a backup failure disables saving to protect the existing file.

A transcript is saved before optional formatting. A formatting or destination-delivery failure therefore leaves text available for review and copying. Destination validation can refuse automatic insertion if the original app or editable field changed.

Configuration can sync through a user-selected folder managed by iCloud Drive or another file-sync app. Choose whether this Mac or the shared configuration initializes **automatic sync**, then saved changes are checked every two seconds; unsaved editor drafts stay local and defer incoming changes until you Save. The saved baseline permits restart/resume. Concurrent edits or diverged revisions pause automatic exchange and preserve a local conflict copy, the shared file and immutable revision snapshots for explicit resolution. Manual **Push**/**Pull** remain available. Snapshots omit history, audio, Keychain keys and machine-specific paths/permissions. Pull first backs up the local configuration and defers automatic application while recording/transcription is active. JustWhisper does not provide a hosted sync service. See [configuration sync](docs/configuration-sync.md) for conflict handling and acceptance checks.

Local CLI/MCP access is off by default. Enable **Allow same-user CLI and MCP commands** and save settings to let local tools submit changes through the running app's private inbox. Read-only commands inspect the atomically saved library. See [docs/local-automation.md](docs/local-automation.md), the integration tool's help and [docs/status.md](docs/status.md) for validation; no network server or third-party API compatibility is implied.

## Validation and remaining work

The release app builds, launches, imports the bundled whisper.cpp JFK speech fixture through local recognition, and restores its saved History after relaunch. The prior extension checkpoint passed 42 Swift tests, with separately enabled real local Whisper/Ollama execution checks; the current extension adds focused provider-route, correction-review, private-file-permission, sync and speaker-alignment fixtures. Gated inference checks are skipped by default. See [feature status](docs/feature-status.md) for the full implementation/acceptance matrix and [docs/status.md](docs/status.md) for observed build/test/runtime results, and [docs/implementation-plan.md](docs/implementation-plan.md) for acceptance criteria. A successful fixture demonstrates pipeline operation, not accuracy on your accent or parity with another product.

This build still needs broader permission, microphone, destination-insertion and real-meeting tests; live cloud tests require your own credentials. Remaining acceptance work includes permissioned Apple streaming operation, evaluated speaker-label quality, confirmed active-call detection, measured user-voice accuracy, and signed/notarized distribution. The user chose independent JustWhisper evaluation; a Flow comparison is not a current acceptance requirement. Automatic folder sync conservatively pauses concurrent conflicts for explicit source selection rather than merging semantic settings edits. Newly implemented calendar, context, shortcut, device, download, folder exchange and integration controls still need permission and live workflow acceptance checks. Provider upload and meeting-duration limits must be respected; the app is not ready to promise arbitrary-length sessions.

Live meeting translation is available under Meetings → Live translation, with From/To selectors and Prepare languages. It uses Apple on-device translation with bounded recent caption updates and requires macOS 15+, supported on-device speech and downloaded language models. Live previews are provisional; final original transcripts are preserved separately. See [implementation and evidence](docs/live-meeting-translation.md).


Help & Tutorial includes a first-run walkthrough, permission links, provider data-flow guidance and optional Keychain-backed transcript-library encryption. Audio, exports and older backups remain separate. External command and file-open requests require approval. Packaging checks bundled native components and publisher notices; this development build remains ad-hoc signed and has not undergone an independent security audit. See [security review](docs/security-review.md).


**Workflows** lets you build ordered app, website, web-search and wait actions with an exact voice phrase. Press Control–Shift–Space to start and stop a voice command, or use Record command. Unique enabled matches run immediately. Customize the shortcut in Configuration. Copy/paste JSON shares one workflow; imports stay disabled until enabled for matching. See [voice workflows](docs/voice-workflows.md) for limits and privacy.


The Mac live-recognition update keeps local Whisper resident, shows actual model readiness, and supports bounded live meeting captions feeding Apple or configured-language-model translation. Workflows have a configurable dedicated shortcut and optional display/fullscreen placement with main-display fallback. Paste targets are captured at Stop; unavailable destinations offer a short copy overlay with hover pause. Genuine failures are collected in the session-only Errors page. See [live local Whisper](docs/live-local-whisper.md) for measured latency and acceptance limits.


The public app name is **JustWhisper** (one word). Legacy internal module, bundle, storage, Keychain, CLI and sync identities remain compatible with the earlier JustWisper build. This preserves existing recordings, encrypted libraries, credentials and integrations. The workspace folder is unchanged.
