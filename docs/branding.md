# Cortala naming

The public application name is **Cortala**. Its installed bundle, executable, menu and sidebar text, icon asset and release downloads use this name. This replaces JustWhisper.

Compatibility identities deliberately remain unchanged: com.justwisper.app, the JustWisper Swift module and source/test directories, Application Support/JustWisper, Keychain service com.justwisper.credentials, the vault header, CLI entry point, local helper protocol and configuration-sync filenames. Existing recordings, settings and credentials are reused in place. The workspace folder remains SuperWisper. The new cortala URL scheme and the legacy justwisper scheme use the same confirmation controls.

The name was selected by the project owner; this rename is not a trademark-clearance certification.
