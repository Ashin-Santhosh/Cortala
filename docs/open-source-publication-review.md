# JustWisper public open-source publication review

Reviewed 2026-10-23. Scope: workspace source, documentation, dependency notices, packaging scripts and the existing ARM64 ZIP inventory. Read-only review apart from this report; no builds, capture, private Library inspection, credential retrieval, recording uploads or publication. This is a practical release review, not a legal clearance opinion. Facts below distinguish observed files from recommendations and unresolved rights questions.

**Recommendation:** prepare a curated source-only alpha first. Do not publish the entire workspace or describe the existing development ZIP as a polished public release. The clearest source-release blocker is the missing license for JustWisper's own work. Binary distribution adds signing, dependency-inventory and clean-machine acceptance work. There is no finding here that implementing dictation functionality itself prevents open-source release.

## Dependency and model licensing assessment

- **FluidAudio 0.17.7:** `Package.swift` pins exactly 0.17.7; `Package.resolved` pins commit `503b4bd1…`. Local Apache-2.0 license, model documents and upstream component licenses are present and copied by `build.sh`. [Upstream versioned license](https://raw.githubusercontent.com/FluidInference/FluidAudio/v0.17.7/LICENSE) confirms Apache-2.0. This supports redistribution subject to its conditions; it does not make all associated model artifacts Apache-licensed.
- **whisper.cpp/GGML:** existing ZIP preserves publisher notices and describes relocation modifications. [whisper.cpp license](https://github.com/ggml-org/whisper.cpp/blob/master/LICENSE) is MIT. Exact released component versions and associated notice correspondence should be recorded in the release manifest; current upstream main is not evidence of every historical artifact's license.
- **OpenMP:** existing ZIP includes `libomp-LICENSE.TXT.txt`. LLVM's [OpenMP license](https://raw.githubusercontent.com/llvm/llvm-project/main/openmp/LICENSE.TXT) is Apache-2.0 with LLVM exceptions. Check the complete actual packaged text and source version, rather than describing every bundled library as MIT.
- **Whisper weights:** OpenAI's [upstream repository](https://raw.githubusercontent.com/openai/whisper/main/README.md) states the code and weights are MIT licensed. The app downloads converted GGML artifacts from another publisher; preserve the original notices and document conversion provenance. Download URLs currently use mutable `main`, but SHA256 rejects changed bytes; immutable URLs would improve availability/reproducibility.
- **Diarization:** the bundled notice explicitly scopes CC-BY-4.0 to selected Community-1 artifacts and distinguishes legacy models. [CC-BY-4.0](https://creativecommons.org/licenses/by/4.0/) permits commercial sharing/adaptation with attribution, a license link and change indications. The local provenance document admits historical segmentation/embedding exports are reconstructed rather than build-attested. This is a disclosure/provenance limitation, not automatically a prohibition. The web tool could not retrieve the exact pinned Hugging Face notice or upstream gated model license during this review; independent current confirmation of those exact publisher documents remains outstanding. No new model download was performed.

## Branding, proprietary inspiration and Apple frameworks

JustWisper has its own displayed name, bundle identifier and generated icon. Those help distinguish it but do not establish trademark clearance or eliminate similarity concerns. Search relevant trademark registers and app names before investing in a public brand; no clearance search was completed. The USPTO discusses [confusion between related marks and goods](https://www.uspto.gov/trademarks/search/likelihood-confusion). Keep marketing and visual presentation independently authored, avoid endorsement implications, and use competitor names only where needed for accurate comparisons.

The US Copyright Office distinguishes unprotected ideas/methods from protected expression in its [copyright FAQ](https://www.copyright.gov/help/faq/faq-protect.html). That supports separating functional inspiration from copied implementation/artwork; it does not settle jurisdiction-specific contracts, patents, reverse-engineering exceptions or trade dress. This review did not inspect any proprietary app binary and cannot certify a clean-room process.

Using SwiftUI, Speech, Translation, ScreenCaptureKit and EventKit through OS frameworks does not require publishing Apple framework source as part of JustWisper. Keep Apple frameworks and downloaded Apple language assets outside the repository and ZIP. Verify SDK agreement, API availability and actual entitlement requirements for the chosen distribution channel. Detailed Translation documentation was inaccessible through the web tool, so this report does not assert clearance under every Apple agreement. Apple's [Developer ID distribution guidance](https://developer.apple.com/developer-id/) describes signing and notarization for software distributed outside the Mac App Store. App Store submission would be a separate sandbox/privacy/review exercise.

Recording law depends on participants and location. As a concrete example, German law restricts unauthorized recording of another person's non-public spoken words ([StGB, official English translation, section 201](https://www.gesetze-im-internet.de/englisch_stgb/englisch_stgb.html)); the English translation may lag amendments. Do not market the app as permission to record everyone. A privacy policy alone does not supply recording consent or establish compliance for users' workplaces.

## Safe publication contents and validation limits

Start with `Sources/`, `Tests/`, reviewed `scripts/` and `tools/`, `Package.swift`, `Package.resolved`, approved icon/assets, curated docs, ThirdPartyNotices, README, a new app license and `.gitignore`. Review benchmark fixture rights and confirm fixtures are synthetic/public before inclusion. Remove personal paths, trial/account details and local-machine statements that do not help contributors. Exclude `.agents/`, `.build/`, `build/`, `dist/`, Models weights/CoreML assets, caches, `.env`, credentials, exported user settings/history, recordings, private benchmark clips, recovery files and user Library data. Do not copy `~/Applications/JustWisper.app` as source.

A sanitized pattern scan over candidate text source/docs/scripts/tests/notices found no matches for common provider-token formats, private-key headers or URLs containing username/password. No secret values or private transcript text were printed. This is a limited heuristic scan, not a comprehensive secret audit; private user storage was deliberately not inspected. There is no Git history here to scan. Re-run a dedicated secret scanner and inspect staged filenames/diff and the final archive before actual publication. The existing ZIP inventory has AppleDouble `__MACOSX` metadata entries; create and inspect a clean release archive rather than uploading it blindly.

Optional improvements: add SECURITY.md with a private reporting route, CONTRIBUTING.md, a support policy, reproducible CI on documented Xcode/Swift versions, an SBOM, release checksums and dependency update tracking. A source-only alpha can precede production signing and full device testing once its license, rights scope, publication contents and honest limitations are resolved.
