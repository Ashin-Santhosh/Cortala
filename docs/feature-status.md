# JustWisper 0.2 feature status

Updated 2026-10-23. This records the native implementation and its validation boundaries. Current accuracy evaluation is independent JustWisper evaluation; the user chose not to obtain a Wispr Flow baseline. Earlier research comparisons are background, not a remaining acceptance requirement. Accuracy on the user's private speech remains unmeasured.

The final source snapshot passed 89 Swift tests across 21 suites (32.981 seconds after a 9.44-second incremental build), including the desktop controls, draft privacy, shutdown recovery and fast-dictation regressions. Seven Python integration tests also passed. The corrected release package was installed in `~/Applications/JustWisper.app` and launched successfully. Live cloud accounts and permissioned recording workflows remain separate acceptance checks.

## Workflow and security checkpoint

The integrated source now passes 132 Swift tests in 30 suites. Help & Tutorial, opt-in authenticated transcript-library encryption, approved external commands/imports and strict native package inventory are implemented; see [security review](security-review.md). Customizable voice workflows add a dedicated command recorder, exact enabled-phrase matching, ordered app/HTTPS/search/wait actions, automatic execution of explicitly recorded commands and disabled-on-import JSON sharing. They do not activate from ordinary dictation, meetings, imports or History retry. Nine focused workflow tests cover import, bounds, matching, cancellation and execution behavior. Window closing and automatic ChatGPT Voice startup remain unsupported. See [workflow guide](voice-workflows.md) and [status](status.md) for installed acceptance.
