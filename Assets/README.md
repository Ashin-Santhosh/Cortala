# JustWisper icon

`JustWisper-icon.png` was generated using the built-in ImageGen tool on 2026-10-21. Source: 1254 × 1254 PNG with alpha.

Final generation prompt: “macOS JustWisper app icon; dark graphite rounded tile, mint/turquoise waveform subtly forming J/W, readable at32px, transparent outer canvas, no text.”

`scripts/build-icon.sh` packages the source into standard macOS icon sizes (16–1024 pixels) and `.build/Assets/JustWisper.icns`. `scripts/build.sh` copies that ICNS into the app bundle and declares `CFBundleIconFile`.
