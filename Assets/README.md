# Cortala icon

`Cortala-icon.png` is the blue/indigo Cortala icon generated with the built-in image-generation tool on 2026-10-24 and approved by the project owner. The white speech waveform and C silhouette connect voice features to the CortexKinematics product family. The PNG includes alpha outside the rounded tile.

The full generation prompt is in `Cortala-icon.prompt.txt`.

`scripts/build-icon.sh` produces standard macOS icon sizes (16–1024 pixels) and `.build/Assets/Cortala.icns`. The same source asset is used in the Windows/Linux interface and on the website. `scripts/build.sh` packages the ICNS and declares `CFBundleIconFile`.
